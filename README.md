# webtransport-benchmark

Code and data for **"Where Does WebTransport Fit? Profiling Browser Transports Across JavaScript Runtimes"** (AINTEC '26).

This work benchmarks and CPU-profiles WebSocket, SSE, short/long polling, and WebTransport (streams and datagrams) on Node.js v26.3.1, Bun v1.3.14 and Deno v2.8.3.

The raw results (`results/`, `logs/`) are too large for git and are included in the Zenodo archive.
